# Node.js `for` Loop Practice

Seven small exercises to practice `for` loops in Node.js — no dependencies required.

## How to use

1. Open `exercises.js` and fill in each `TODO` using a `for` loop.
2. Check your work:

   ```bash
   node node-practice/run.js
   ```

3. Stuck? Compare against the reference implementation:

   ```bash
   node node-practice/run.js --solutions
   cat node-practice/solutions.js
   ```

## Exercises

| # | Function | Concept |
|---|----------|---------|
| 1 | `countUpTo(n)` | classic `for` loop, building an array |
| 2 | `sumUpTo(n)` | accumulating a value across iterations |
| 3 | `evensUpTo(n)` | stepping by more than 1 |
| 4 | `fizzBuzz(n)` | loop + `if`/`else` branching |
| 5 | `findMax(numbers)` | `for...of` over an array |
| 6 | `reverseArray(arr)` | looping backwards (counting down) |
| 7 | `drawSquare(size)` | nested `for` loops |
